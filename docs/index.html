Operating principles

How I try to make the work easier to trust.

  1. Ask early when expected behavior is unclear.
  2. Keep private client data out of public proof.
  3. Write bugs with enough detail for another person to reproduce them.
  4. Use AI as draft support, then verify sources and edit manually.
  5. Prefer small verified releases over impressive claims.
